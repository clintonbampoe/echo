# .agents/ — Project Agent Skills & Conventions

This directory is the **canonical location** for project-level agent skills and conventions.
It follows the [Agent Skills standard](https://agentskills.io/) and is read automatically by:
OpenCode, Cursor, Codex, GitHub Copilot, Amp, Gemini CLI, Cline, Kilo, and others.

---

## Structure

```
.agents/
├── skills/          # Individual skill folders (SKILL.md + scripts/ + references/ + assets/)
├── plugins/         # Plugin marketplace configurations (JSON)
├── mcp/             # MCP server configurations (reserved)
└── learning-notes/  # Auto-generated by master-concept-explainer (gitignored)
```

---

## How Skills Are Installed

**Do not create skill folders manually.** Use the `skills` CLI:

```bash
# Project skills (installed into .agents/skills/)
npx skills add dotnet/skills --all --yes
npx skills add neondatabase/postgres-skills --yes
npx skills add docker/skills --yes
npx skills add anthropics/skills --yes
npx skills add peterbamuhigire/linux-skills --yes

# Personal skills (global, your machine only)
npx skills add DietrichGebert/ponytail --skill ponytail -g --yes
npx skills add jayrha/concept-explainer -g --yes
npx skills add DreambigOu/ELI5 --skill eli5 -g --yes
npx skills add ThepExcel/master-concept-explainer -g --yes
```

Each skill installs as `.agents/skills/<skill-name>/` containing:
- `SKILL.md` — entry point with YAML frontmatter (`name`, `description`) + instructions
- `scripts/` — executable helpers
- `references/` — documentation, templates, checklists
- `assets/` — static files
- `evals/` — test cases (optional)

## Discovery

Tools discover skills by walking up from the current directory to the git root,
checking `.agents/skills/` at each level. Nested `.agents/skills/` in subdirectories
are scoped to that subtree (monorepo-friendly).

---

## Adding a New Project Skill

1. Install via `npx skills add <repo> --skill <name> --yes`
2. Or, for a custom skill: create `.agents/skills/my-skill/SKILL.md` with frontmatter
3. Reference it in `AGENTS.md` if it should be discoverable by all agents

## Vendor Shims (Not Used)

We do **not** maintain symlinks in `.claude/`, `.github/`, `.opencode/`, etc.
The Agent Skills standard specifies `.agents/skills/` as the canonical cross-tool path.
All supported tools read it natively.
