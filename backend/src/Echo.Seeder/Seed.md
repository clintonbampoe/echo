# Seed Data Reference

## Running the seeder

```bash
docker compose run --rm seeder
```

Default config:

| Option | Value |
|---|---|
| `Seed` | `42` |
| `Reset` | `false` |
| `BatchSize` | `2000` |
| `ReferenceNow` | `2026-10-01T00:00:00Z` |

All of these are deterministic — the same inputs produce the same data on
every run.

## Data volume

| Option | Value |

The seed creates **6 congregations**: 1 big (`Grace Chapel International`)
and 5 small. The big congregation is the only one with meaningful data
volume — test pagination and query profiling against it. The small
congregations have too few rows to exercise anything.

change them. Regenerate with the query below if they drift.

### Regenerate the admin list

```sql
SELECT
    c."Name"         AS "CongregationName",
    u."Name"         AS "UserName",
    u."EmailAddress" AS "UserEmail"
FROM "Congregations" c
LEFT JOIN "Users" u
    ON u."CongregationId" = c."Id"
   AND u."DeletedAt" IS NULL
WHERE c."DeletedAt" IS NULL
ORDER BY c."Name", u."Name";
```
